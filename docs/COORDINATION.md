# Coordination

Decision: GitHub is the source of truth. Anything else is a funnel into it.

- **Issues** for tasks, architecture proposals, dataset sources.
- **Discussions** for open questions and results threads.
- **Reddit / HN** for the launch post only. Link back here.
- **Discord**: only if more than ~20 active people ask for it. Chat does not persist; issues do.

## Contributing data

Rules, to be refined before the first hour is accepted:

1. Source must be public domain, CC0, or recorded by the contributor with consent to release under CC0. CC-BY sources are accepted only in a separate attributed track, since the main dataset is CC0.
2. Every clip carries: source URL or recording consent, license, speaker id, language, transcript.
3. No audio generated by open TTS or cloning tools. Synthetic audio from closed commercial TTS is allowed only in the distillation track, tagged as such.
4. Target format and loudness normalization are defined in `configs/data.json` (to be written).
